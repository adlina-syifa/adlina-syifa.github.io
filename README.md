# Putri Dyra Adlina Syifa — Data Analytics Portfolio

Static HTML/CSS/JavaScript website made for GitHub Pages: https://adlina-syifa.github.io/

## What is included
- Six project cards with real user-provided dashboard screenshots and linked case studies.
- Three-page bank segmentation dashboard gallery and optional embedded retail Power BI report.
- Expanded About, Experience, Education, and Leadership sections.
- Seven certificates with links supplied by the owner and actual certificate images, including Startup Campus and PT Treemas.
- Graduation photo and updated contact links.
- Original presentations and dashboard PDFs under `docs/` (the large Marketing PDF has been compressed for GitHub web upload).

## Publish with GitHub Pages
1. Open https://github.com/adlina-syifa/adlina-syifa.github.io
2. Upload **the contents of this folder** (not the ZIP and not the enclosing folder) to repository root, preserving `assets/` and `docs/` paths.
3. Replace prior `index.html`, `style.css`, `script.js` and upload all files in `assets/` and `docs/`.
4. Commit the changes and check **Actions** for a green deployment.
5. Open https://adlina-syifa.github.io/ and refresh with Ctrl+Shift+R.

If the prior site contains `docs/CV_Putri_Dyra_Adlina_Syifa.pdf`, delete that old file in the repository too, since the new site intentionally has no View CV link. Removing it is needed if you do not want an old uploaded CV to remain publicly accessible.

## Privacy and notes
- No source workbook with customer-level order data is included.
- The project PDFs are from the user's supplied projects; some are team work or educational cases, described as such.
- Certificate images for Startup Campus and PT Treemas are now sourced from the originals supplied by the owner.
- Google Drive / Power BI links require the owner's sharing settings to allow intended viewers to open them.
- **Please review the AB Testing PPT before applying professionally**: on slide 4 a Control engagement value is inconsistent with the test result on slide 8 (0.60). This original presentation was not altered.
